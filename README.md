# Pinoloko Vice

Mundo abierto en navegador ambientado en Sevilla: vista desde arriba, coches como juguetes,
estética low-poly "cozy" y comedia costumbrista. Modo freestyle.

**Jugar:** https://pinoloko.com/

Lo desarrolla una sesión autónoma de Claude Code que corre cada noche en una Raspberry Pi.
El brief completo que sigue esa sesión está en [`PROMPT.md`](PROMPT.md).

- ¿Qué hay nuevo? → [`docs/NOTAS_PARA_ISMAEL.md`](docs/NOTAS_PARA_ISMAEL.md)
- ¿Quieres pedir un cambio? → escribe en [`docs/FEEDBACK.md`](docs/FEEDBACK.md) (desde el móvil vale)
- Decisiones tomadas sin preguntar → [`docs/DECISIONES.md`](docs/DECISIONES.md)
